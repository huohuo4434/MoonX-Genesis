# MOOX 发布前升级包（2026-07-30）

正式站点：`https://mooxintel.com`

本升级包基于用户上传的完整项目源码制作。它是**本地代码升级包**，尚未替用户提交 Git、推送仓库或部署 Vercel Production。

## 1. 明日观点

- 首页在“今日观点”下方新增 `#tomorrow` 明日观点区域。
- `/member/tomorrow` 不再显示空白页面，直接跳转到 `/#tomorrow`。
- 北京时间 20:00 前显示：目标日期、固定发布时间和动态倒计时。
- 北京时间 20:00 后，页面自动刷新并检查正式批次。
- 有效会员在正式批次发布后看到完整明日预测；未登录、普通用户只看到会员锁定提示。
- 页面不再显示空白“失效位”、虚假概率或旧日期预测。
- 19:30/19:50/20:00 三次任务均会尝试生成真实技术价位，20:00 只锁定和发布已通过校验的结果。

## 2. 六爻与技术价位分工

- 六爻：只负责方向、路径、强弱和时间窗口。
- 技术模块：使用真实日 K 结构、波段聚类、平台区、EMA60、MACD 零轴与动能生成价格区间。
- 支撑和压力默认采用价格区间，而不是单一价格。
- 发布前校验禁止：`放量突破`、`前一日高低点`、`昨日高低点`、日期高低点、前高前低等模糊表达。
- 行情数据不足或无法形成结构共振时，返回 `TECHNICAL_PRICE_DATA_UNAVAILABLE`，不编造价位。
- 复杂路径不会再因为包含“涨”字而被错误归类，例如：
  - 先涨后跌 / 冲高回落 → 下跌方向族
  - 先跌后涨 / 探底回升 → 上涨方向族

## 3. 历史准确率

正式支持九类预测和实际走势：

1. 上涨
2. 下跌
3. 震荡
4. 震荡上涨
5. 震荡下跌
6. 先涨后跌
7. 先跌后涨
8. 冲高回落
9. 探底回升

验证规则：

- 路径型预测优先使用 15 分钟正式交易时段 K 线。
- 阈值由 ATR 和资产类别动态计算，不再用一个固定百分比验证所有资产。
- 结果分为：完全命中、部分命中、未命中、无法验证。
- 早期只保存涨跌方向的记录标记为 `LEGACY_DIRECTION_ONLY`，不计入完整路径命中率。
- 缺少盘中 K 线时，路径型预测标记为 `UNVERIFIABLE`，不能仅凭日线猜测路径。
- 历史页面展示原始预测、实际 OHLC、实际路径、高低点出现时间、分项评分和验证说明。
- 新验证记录保存 15 分钟收盘路径，并在历史卡片中显示实际路径图；发布时锁定的第一支撑区、第一压力区同步作为背景区间。
- 加权命中率：`（完全命中 + 部分命中 × 0.5）÷ 有效验证数`。

## 4. 老师知识库

知识包：`data/imports/moox-teacher-knowledge-batch-20260730.json`

包含：

- 46 节原始转写课程
- 10 条老师规则
- 21 个高价值案例
- 3 个概念
- 3 条经典原话
- 4 套方法

安全约束：

- 全部导入为 `DRAFT`。
- 每条规则、案例、概念、原话和方法必须指向具体 `sourceLessonRef`。
- 每个来源引文必须是对应原始转写中的逐字片段；预览阶段会拒绝非逐字来源。
- 原始转写全文保留，不覆盖。
- 没有卦盘截图的案例，主卦、变卦、动爻、世应、月建、日辰等字段保持空值，并写入 `needsAdminFill`。
- 不根据转写错误自行猜卦。
- 标记为“来源B（待确认）”的课程不自动与主老师规则混合。

### 导入步骤

1. 管理员登录。
2. 打开：`/admin/teacher-knowledge/import`
3. 选择并上传：`moox-teacher-knowledge-batch-20260730.json`
4. 点击“预览”。
5. 确认预览无错误后，点击“确认导入（DRAFT）”。
6. 到审核页面逐项核对、补卦图字段、批准规则。

导入页已增加 JSON / Markdown / TXT 文件选择，不再要求把 45 万字节 JSON 全部手工粘贴。
