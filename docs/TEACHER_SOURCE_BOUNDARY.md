# 教师知识来源与边界审计

## 已采纳的明确规则

- 金兔子案例出现时家拆补转盘与时家置闰转盘，定局法必须显式记录，不能默默混用。
- 行情先拆为上涨、下跌、震荡，必要时另看整体走势、当前价格、高点和低点。
- 日干、时干、值符、值使及其天盘/地盘/暗干位置是主趋势核心。
- 必须结合月令旺衰、空亡、入墓、门迫、击刑，不能只按单个吉门凶神机械断。
- 丙丁、九天、天冲、生门/开门偏多头或上冲；庚辛、白虎、九地偏抛压或下沉；腾蛇偏反复震荡。
- 价格宫数字只能形成候选区间，不能直接驱动自动下单。
- 奇门金融断法必须复盘，预测与交易决策分离。

## 明确未冒充的规则

老师资料没有给出一套完整、可编程的“上涨宫/下跌宫/震荡宫”取宫算法。V7.20.0.5 使用日干/时干/值符/值使加权、门星神干、月令、空墓迫刑的 MOOX 数字协议；所有结果均保留来源边界字段。

## 八字边界

八字老师关于财为用、食伤生财、从财/从儿等内容，只用于私人投资适配度；比劫重等风险提示只影响个人仓位与风控，不参与 BTC、黄金、美股、A股等公共市场方向投票。
