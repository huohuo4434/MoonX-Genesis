# MOOX 关键人物八字旁证规则

版本：2026-08-09

## 定位

关键人物八字只用于月度、季度、年度等中长期背景旁证，不直接决定下一交易日或日内涨跌。

MOOX 固定优先级：

1. 资产自身的六爻／周卦／月卦／更大周期卦决定正式方向。
2. 多周期同向形成玄学共振；冲突则明确写“方向不明确”。
3. 奇门用于时间窗口。
4. 关键人物八字仅作为中长期旁证票，不得覆盖资产自身卦象。
5. 技术分析只负责支撑、压力、入场、止损与执行位置，不拥有方向投票权。

## 适用对象

仅对与资产高度绑定的人物使用，例如创始人、CEO、控股股东、极高比例持仓者或公司战略的核心决策者。普通高管、短期代言人或关系弱的人不纳入。

## 数据要求

- 出生年月日和出生地必须有可追溯来源。
- 出生时辰未知时必须标记 `TIME_UNKNOWN`，降低权重，不得伪造时柱。
- 如果出生时间位于时辰边界，必须保留候选盘并用可核实人生事件校时；不能为了得到想要结论强行选盘。
- 必须记录来源、可信度和校时依据。

## 分析流程

1. 日主与月令；
2. 命局“病”和“药”；
3. 喜用顺序；
4. 大运、流年；
5. 用公开可核实的重大人生／事业事件回验；
6. 再映射到公司／资产的中长期背景；
7. 只作为资产自身卦象之外的旁证，不做覆盖。

## 权重

- 默认旁证权重：5%。
- 出生时间可靠且历史回验充分：最高 10%。
- 时辰未知或回验不足：0–5%。
- 不参与日度方向投票。
- 不参与技术点位计算。

## 输出

页面必须把它标成“关键人物八字旁证”，并同时显示：

- 人物与资产的绑定关系；
- 数据可信度；
- 适用周期；
- 八字背景方向（利好／利空／不明确）；
- 与资产卦象是否同向；
- 不能直接推导短线涨跌的提示。
