# MOOX AI交易公开台与历史验证稳定性升级 V6.3

## AI交易公开台

- 会员页面不再在首屏请求中执行建表、完整交易系统检查或Bitget读取。
- 页面先打开，再通过受权限保护的API读取15秒共享只读快照。
- 数据库读取2.5秒超时；超时保留最近一次可读快照，页面不会整页卡死。
- 浏览器8秒超时、60秒可见页刷新，恢复网络或重新回到页面会立即重试。
- 建表和外部交易所同步仍只在管理员/服务器任务路径执行。

## 公开历史验证

- `/verification` 继续完全公开。
- Supabase JSON读取增加60秒缓存、同请求去重、4秒超时和最近可读数据回退。
- 读取路径不再先执行 `listBuckets/createBucket`。
- `/api/public/verification` 增加公共60秒缓存、CSV星级字段、星级分档和高低星趋势分析。
- 有效样本不足30条时也显示命中率，但明确标记“暂定”。
- 1星至5星分别展示样本、完全命中、部分命中、未命中和加权命中率。
- 自动比较4—5星与1—2星，并判断当前样本是正向、平坦、倒挂还是不足。

## 统计纪律

- 完全命中=1，部分命中=0.5，未命中=0。
- 无法验证不进入命中率分母，但保留公开记录。
- 不允许因最初几天表现不好而删除记录。
- 只有系统测试、休市、行情源错误或事先公布的试运行基准，才能按固定规则排除；排除原因必须公开。
