# MOOX V7.20.8 App流畅度优化

本版本只优化 Web / 移动端呈现与读取路径，不修改预测方向算法、交易写入、Cron、Prisma 或数据库结构。

主要变化：
- 首页使用 Suspense 流式骨架，慢数据不再阻塞可见界面。
- 今日权限判断与今日预测读取并行执行。
- 官方账户公开持仓移出首页服务端关键路径，改为首屏后异步读取，并使用短期公共缓存。
- 首页最近验证单独流式读取，不再拖住今日共振雷达。
- 增加全站 `app/loading.tsx`，路由切换立即显示 App 风格骨架。
- 恢复主导航 Next.js 预取，会员下拉在 hover/focus 时预取目标页。
- Navbar 与新会员欢迎引导共享 `/api/auth/session-lite` 单例请求和 2 分钟浏览器会话缓存，避免重复请求。
- 全局历史 DOM 兼容代码改为空闲时延迟加载；MutationObserver 工作按动画帧批处理。
- 手机首页不再执行桌面“明日观点”DOM 插入请求。

安全边界：不新增环境变量，不修改交易执行、订单写入、预测正式方向、会员权限规则和数据库 schema。
