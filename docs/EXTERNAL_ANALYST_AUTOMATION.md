# MOOX 外部分析师监测与六爻优先级

## 核心原则

1. 六爻周度、月度和长期卦象是一级方向判断。
2. 奇门用于时间验证。
3. 技术分析用于确认入场、止盈、止损和失效位置。
4. 外部博主观点只属于技术参考层，不能反向改写六爻方向，也不能单独触发下单。

## 两个外部方法的分工

### haliluya8911

用于短线“恐慌急跌后的确认反弹”模块：

- 先出现极端下跌、超卖或重要支撑扫损；
- 不直接接飞刀；
- 等5分钟或15分钟重新站回关键位置；
- 反弹到第一层压力优先减仓；
- 与周度卦象冲突时，只允许更小风险、更短持仓，或直接放弃。

### BTCTW0

用于波段和中长期的江恩技术地图：

- 提取支撑、压力、突破位和失效位；
- 提取日线/周线实体K确认条件；
- 提取江恩时间窗口；
- 用于优化回踩入场、突破确认、止盈和止损；
- 只有完成至少10个事前锁定样本验证、取得1%至3%受限权重且与六爻主方向一致时，才可辅助点位；否则只展示。

## 自动监测配置

当前生产采集由新加坡 VPS 上唯一的 `moox-x-collector.timer` 每15分钟运行；不要同时恢复Windows计划任务。会员重点表的第一、第二梯队只改变采集顺序和展示排序，不等于预测权重。

VPS向网站提交采集批次时使用：

```text
MOOX_X_COLLECTOR_SECRET=至少24位的随机密钥
```

该密钥只保存在VPS和网站服务器环境变量中，不进入仓库、浏览器或会员页面。

以下是备用的服务器直采模式，不与当前VPS生产采集同时启用。只有停用VPS采集器并完成切换验收后，才可在Vercel配置：

```text
X_BEARER_TOKEN=你的X开发者Bearer Token
MOOX_EXTERNAL_ANALYST_ENABLED=true
MOOX_EXTERNAL_ANALYST_REFRESH_MINUTES=15
```

如果你有自己的 JSON feed 代理，也可不用 X_BEARER_TOKEN，改为：

```text
MOOX_EXTERNAL_ANALYST_FEED_URL=https://你的服务地址/posts.json
```

JSON feed 格式：

```json
{
  "posts": [
    {
      "username": "BTCTW0",
      "id": "1234567890",
      "text": "BTC在63412上方保持强势，突破67300后关注70380。",
      "createdAt": "2026-08-06T00:00:00.000Z",
      "url": "https://x.com/BTCTW0/status/1234567890"
    }
  ]
}
```

## 自动运行

升级后新增：

```text
/api/cron/external-analysts
```

Vercel 每15分钟调用一次该路由。当前生产环境不配置 `X_BEARER_TOKEN` 和 `MOOX_EXTERNAL_ANALYST_FEED_URL`，因此该路由只执行无源状态刷新，不会向X发起第二套采集；真正的帖子采集只有VPS timer。`/api/cron/x-intelligence-report` 只读取已入库数据生成报告，也不抓取X。

## 安全限制

- 多品种帖子不会自动把同一组数字套到所有品种上；只有明确对应单一品种的帖子才可修改价格计划。
- 未通过历史样本门禁的普通外部观点与六爻方向冲突时，只记录冲突提醒，权重为0%，不修改方向、信心、止盈或止损。
- 通过至少10个事前锁定样本门禁的外部观点，与六爻同向时才可能按1%至3%的受限权重辅助信心和技术点位；仍不得取得方向权或制造开仓资格。
- 调整后的第二目标盈亏比低于1:1.2时，系统保留原计划。
- 外部观点不会把 `ready=false` 改成 `ready=true`，因此不能单独触发真实订单。
- X API未配置或读取失败时，原有10品种三周期交易系统继续运行。
- 重点分析师少于10个事前锁定且可验证的样本时，行情预测权重固定为0%；达到60%/65%/70%加权命中率后，辅助权重上限依次为1%/2%/3%。
- 梯队排名、关注人数或单次命中不能直接增加方向权重；外部来源永远不取得MOOX正式方向权。
