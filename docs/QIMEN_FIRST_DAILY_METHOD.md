# MOOX V7.20.0.5：奇门优先的次日日分析方法

## 1. 正式层级

1. **奇门遁甲：第一方向依据。** 先给出次日看涨、看跌或震荡，以及主要时间窗口。
2. **六爻：辅助确认与风险提示。** 同向时提高共振置信度；冲突时保留奇门方向并降低置信度，不再让六爻反向覆盖奇门。
3. **技术分析：执行层。** 只提供支撑、压力、入场、止损、失效位和目标位，不参与方向投票。
4. **个人八字：私人适配层。** 只评估某个人是否适合偏财、当期风险承受和仓位倾向；不得改变公共市场预测。

## 2. 用神如何取

金融市场奇门用神不是先看用户八字。正式公共研究以“所问对象与所问事项”为中心：

- 主用神：时干天盘、时干地盘，代表所问市场/资产及其现实根基；
- 次用神：日干天盘、日干地盘，代表起念与问题本身；
- 主趋势权重：值符、值使；
- 资金与价格：甲子戊、生门；
- 多头力量：丙、丁、九天、天冲、生门、开门；
- 空头压力：庚、辛、白虎、九地、死门、惊门；
- 震荡与速度：腾蛇、天冲、驿马。

不同产品只增加“对象属性和观察组”，不把五行对象属性机械等同于涨跌。例如黄金属金，庚辛可参与对象识别，但不能因为出现庚辛就直接判跌；原油的丙丁/天英也不能因为属火就直接判涨。

## 3. 吴老师与金兔子的知识如何分层

- 吴老师课程用于建立“研究对象—用神—判断链—周期”的基础规则库；
- 金兔子的资料用于市场化象意、月令旺衰、日干/时干、值符/值使、九天九地、腾蛇天冲、高低点数字和复盘纪律；
- 资料中没有完整公开“上涨宫/下跌宫/震荡宫”的人工取宫算法，因此系统不冒充老师原法。
- MOOX 另建公开、可复现的数字评分协议，并在每条结果中明确标注 `MOOX_DIGITAL_PROTOCOL`。

## 4. 排盘时间

不固定北京时间 20:00。若同一资产/目标日已有已保存奇门依据，优先复用其中的起局时间；首次生成时，系统在目标交易日前一晚 19:00—22:59 的研究窗口内，以“目标日期+资产”确定稳定、可复盘的起局时间。同一资产/目标日无论重试多少次都不换盘。

## 5. 自动发布的安全闸门

- 九宫地盘干、外八宫九星、八门、八神必须通过唯一性校验；
- 盘面校验失败时不覆盖原方向，并标记 `QIMEN_UNAVAILABLE`；
- 奇门与六爻冲突时，奇门方向保留、置信度下降、冲突显式展示；
- 宫位数字只能作为候选观察区，不直接变成自动下单价格；
- 不连接 Bitget 下单，不修改杠杆，不触碰支付、认证、会员、验证历史。

## 6. 每日复盘

每条日分析必须保存：起局时间、四柱、节气、阴阳遁、局数、值符、值使、九宫、用神宫、方向评分、六爻是否同向、技术执行位、最终结果和错误原因。验证后进入 Learned 状态，持续校准 MOOX 数字协议，但不得偷偷改写已发布预测。
