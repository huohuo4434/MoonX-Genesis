# MOOX预测治理 V1

## 唯一主线

大周期确定市场环境，当前周卦或阶段卦锁定方向，奇门拆时间窗口，缠论与技术寻找位置，AI过滤信息并控制风险，量化系统按规则执行。

## 日分析

不单独要求日卦。日分析由当前有效周卦或阶段卦拆解，并按真实交易日历生成。股票不生成周末正式预测；7×24加密资产保留自然日。技术结构没有确认时输出“方向不变，暂不交易”。

## 正式方向词库

上涨、震荡上涨、先跌后涨、震荡、先涨后跌、震荡下跌、下跌。

整固／盘整／横盘归为震荡；探底回升归为先跌后涨；冲高回落归为先涨后跌。

## 锁定与版本

正式发布后原记录不可覆盖。修订必须生成新版本并保存修改原因。当前页只展示最新有效版本；历史版本、未命中和部分命中永久保留。

## 前5

前5不是最看涨的5只，而是方向明确、位置合适、盈亏比合格且本周存在执行窗口的标的。A股仅共识上涨可进入前5；极强看跌只作风险备注。
